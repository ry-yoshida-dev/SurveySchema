# special

## Overview

Special responses that any question can offer beside its substantive answers, such as ``Don't know``.

## Components

| Component | Description |
|---|---|
| [response.py](response.py) | `SpecialResponse`, one special response with its code and label, shown or only recorded when volunteered. |
| [responses.py](responses.py) | `SpecialResponses`, the special responses of one question. |
| [kind.py](kind.py) | `SpecialResponseKind`, such as don't know, no opinion, refused, and does not apply. |
