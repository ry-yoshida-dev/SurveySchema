# choice

## Overview

Options of choice, ranking, best-worst, and constant-sum questions.

## Components

| Component | Description |
|---|---|
| [option.py](option.py) | `ChoiceOption`, one option, which may be exclusive or take free text. |
| [options.py](options.py) | `ChoiceOptions`, the ordered options of one question, including yes-or-no options. |
